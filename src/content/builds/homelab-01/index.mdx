## Why it exists

Learning security means learning how things break. The only honest way to practise that is on machines built to be broken, that you own, on a network that can't leak. homelab-01 is that place. Nothing in it is real, and nothing real can reach it.

## The setting that matters most

Each virtual machine's network adapter has a mode, and that one dropdown decides what a practice VM can talk to. Switch modes and watch what the practice VM can reach:
